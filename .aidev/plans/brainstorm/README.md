## 🔄 Como funciona o fluxo

```
backlog/ (ideia bruta)
    ↓ aidev brainstorm <id>
brainstorm/ (ideia refinada — você está aqui)
    ↓ aidev create-feature <id>
features/ (feature estruturada com sprints)
    ↓ aidev start <feature-id>
current/ (em desenvolvimento)
    ↓ aidev complete <feature-id>
history/ (concluída)
```

---

## 📋 Comandos

```bash
# Iniciar brainstorming interativo de um item do backlog
aidev brainstorm <backlog-id>

# Gerar template automático sem interação
aidev brainstorm <backlog-id> --auto

# Converter brainstorm aprovado em feature estruturada
aidev create-feature <brainstorm-id>
```
